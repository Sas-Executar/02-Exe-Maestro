├─ 4. Copiloto (Workflow e Agentes)
│  ├─ Princípios de Operação
│  │  ├─ Fonte Canônica: O banco de dados é a única verdade; o Mapa-OS é apenas projeção.
│  │  └─ Metodologia de Ação: Capturar -> Interpretar -> Estruturar -> Priorizar -> Confirmar -> Executar -> Verificar -> Registrar -> Emitir -> Adaptar.
│  ├─ Workflow Agentic (Ciclo de Vida)
│  │  ├─ SYNC: Sincronização de dados externos [CIANO]

│  │  ├─ PRE_APPROVE: Verificação de pré-requisitos [AMARELO]
│  │  ├─ DECOMPOSE: Quebra em subtarefas [CINZA]
│  │  ├─ EXECUTE: Disparo de ferramentas/skills [LARANJA]
│  │  ├─ RECONCILE: Ajuste de estado pós-execução [TURQUESA]
│  │  ├─ REPORT: Geração de evidência verbal/visual [VERDE]
│  │  └─ REPLAN: Ajuste de rota baseado em desvios [AMARELO]

│     ├─ Ação: Execução automática de skill executar-* [LARANJA]

│     ├─ Notificação: Alerta de conclusão ou falha
│     ├─ Retry: Política de tentativa em caso de erro [VERMELHO]
│     ├─ Pausa/Retomada: Controle manual da rotina
│     ├─ Auditoria: Rastro de todas as execuções automáticas

│        ├─ Automação 2: Atualização de status de projeto baseada em commits/docs
│        └─ Automação 3: Agendamento de reuniões de revisão baseado em marcos atingidos
